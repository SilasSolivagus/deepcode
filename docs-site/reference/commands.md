# 命令参考

交互式 TUI 里全部可敲的斜杠命令。日常用法与快捷键见[命令与快捷键](/usage/commands)，这一页是**全表**。

::: tip 菜单里看到的不是全部
输入 `/` 浮出的菜单有 33 条，但**实际能敲的有 50 条**——另外 17 条没进菜单，只能靠这一页发现。
下面用 🔍 标出它们。
:::

## 模型与思考

| 命令 | 作用 |
|---|---|
| `/model` | flash ↔ pro 切换；`/model <名>` 直接指定 |
| `/think` | thinking 模式开关 |
| `/setup` | 重新配置 API key（模型 / 搜索 / 图片识别） |
| 🔍 `/output-style` | 切换输出风格 |
| 🔍 `/theme` | 切换配色主题 |

## 权限模式

| 命令 | 作用 |
|---|---|
| `/accept` | `acceptEdits` 开关 |
| 🔍 `/plan` | 进入 / 退出 plan 模式（只读）。**退出时恢复进入前的模式**，不是一律回 default |
| 🔍 `/dontask` | `dontAsk` 开关：读放行，任何需确认的写操作自动拒绝、不弹窗 |
| 🔍 `/cycle-mode` | 循环切换权限模式，等价于 Shift+Tab |

::: warning yolo 下这三个都不生效
`--yolo` 启动时，`/plan`、`/dontask` 会直接提示「所有操作均已放行」并退出，不改变任何状态。
:::

完整语义见[权限模式](/usage/permissions)。

## 后台与自动化

| 命令 | 作用 |

## 非斜杠的输入前缀

| 前缀 | 作用 |
|---|---|
| `@<路径>` | 引用文件，带补全 |
| `!<命令>` | 直接跑 shell，不经过模型 |
| `/` | 浮出命令菜单 |

## 只有快捷键、没有命令的操作

| 操作 | 键 |
|---|---|
| 循环切换权限模式 | `Shift+Tab`（也可敲 `/cycle-mode`） |
| 中断当前轮 | `Esc`（可中途转向，不必等它跑完） |
| 退出 | `Ctrl+C` 连按两次 |

::: info auto 模式没有专属命令
auto 模式只能通过 `Shift+Tab` 或 `/cycle-mode` 循环进入，**没有 `/auto` 这个命令**。
:::

## 命令来源

菜单里那 33 条定义在 `src/tui/suggest.ts` 的 `BUILTIN_COMMANDS`；带 🔍 的那些直接在
`src/tui/useChat.ts` 与两个渲染器组件里处理，没有登记进菜单。**这一页以实际能敲的为准。**
